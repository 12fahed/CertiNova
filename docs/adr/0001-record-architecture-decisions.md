# 0001. Record architecture decisions

- Status: Accepted
- Date: 2026-11-15

## Context

The revamp changes every part of the stack. People must know why each choice was made.

## Decision

Write one ADR for each important decision in `docs/adr`. Use the template in `0000-template.md`. Do not edit an accepted ADR. Write a new ADR that supersedes it.

## Consequences

Reviews can point to an ADR. A change to a decision needs a new ADR in a pull request.
